# Harmony Music Academy — Frontend Demo

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code / terminal.
3. Run:
   npm install
4. Then:
   npm run dev
5. Open the localhost URL shown by Vite (usually http://localhost:5173).

This is a frontend-only demo. Login, checkout, course access, and secure video are simulated in the UI.
